# Plan 01-01: Workspace, overlay lifecycle, and first copy slice

## Objective

Create the pnpm workspace and a runnable Vite demo where activating the overlay highlights elements and copies a normalized HTML preview with best-effort Vue source identification.

## Tasks

- [x] Create root pnpm workspace, strict TypeScript config, Vite library build, and demo app.
- [x] Implement shared constants, public types, source normalization, HTML previews, and clipboard writes.
- [x] Implement a separate Vue overlay app in an open Shadow DOM with a dev-only mount and idempotent `init()`.
- [x] Implement toggle/hold activation, input/IME guards, hover hit-testing, selection box and label.
- [x] Implement click-to-copy, success/error feedback, `window.__VUE_GRAB__`, `vue-grab:init`, and `dispose()`.
- [x] Add compiler-free source fallback through `__vueParentComponent.type.__file`.
- [x] Build the demo with nested components, a keyed list, an ignored subtree, and a reactive counter.
- [x] Add unit tests for previews, source normalization, and the fallback copy grammar.

## Verification

- `pnpm --filter vue-grab typecheck`
- `pnpm --filter vue-grab build`
- `pnpm --filter vue-grab test`
- Browser smoke: activate, hover, copy, inspect clipboard.
- Production demo build: no `data-vue-grab-loc` or `__VUE_GRAB__` in output.
